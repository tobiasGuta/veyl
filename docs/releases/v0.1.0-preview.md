# Veyl v0.1.0-preview

Veyl is a native terminal emulator for Fedora 45 with a compact tab strip, a Settings tab, and optional frosted translucency on GNOME Wayland.

## What’s included

- Searchable command palette, configurable shortcuts, and terminal search.
- Tabs and split panes, pane zoom, font resizing, and optional directory titles.
- Launch profiles, color schemes, and a Bash prompt editor with an editable smart preset.
- Clickable web links, a terminal context menu, and a multiline paste preview.
- A user-local installer that registers the launcher and icon.

## Install and uninstall

After checking out this release, install the Fedora development dependencies listed in the [README](../../README.md#quick-start--fedora-45), then run:

~~~bash
cargo build --locked --release
python3 scripts/install-local.py install
~~~

Open **Veyl** from the application grid. Press **Ctrl+Shift+P** for the command palette.

To remove Veyl while keeping its settings:

~~~bash
python3 scripts/install-local.py uninstall
~~~

## Known limitations

- Frosted mode uses an opaque background where compositor blur is unavailable. Turn off **Frosted background** for plain transparency.
- The prompt editor applies to Bash. The smart prompt’s timing indicator requires Bash 5.3 or newer.
- Closing a tab or pane can terminate jobs in it. Veyl does not restore running sessions when reopened.
- See [verification status](../STATUS.md) for the desktop checks completed and still outstanding at the preview candidate.
