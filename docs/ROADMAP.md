# Roadmap

## Fedora preview

The current implementation includes tabs, split panes, search, the command palette, the Settings editor, Bash prompt presets, and a user-local installer. The [preview notes](releases/v0.1.0-preview.md) describe the build. Check [verification status](STATUS.md) for the release evidence and outstanding checks.

## Next

- Warn before closing a pane with a running foreground job.
- Add command navigation, copying command output, and optional completion notifications.
- Save project layouts with tabs, pane arrangements, and launch profiles.
- Add launch profiles for Toolbx and SSH using the user’s existing OpenSSH configuration.
- Prepare Fedora RPM packaging and AppStream metadata.

## Later

- Expand accessibility and contrast options.
- Investigate blur behavior across compositors and themes.
